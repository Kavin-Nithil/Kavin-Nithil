I'm a backend engineer with **4 years of experience** building Python/Django microservices for digital banking and payments, used by **10+ banks across 6+ countries**. I'm currently the **Founding Engineer at StudioLot**, an AI film-production startup, where I built the backend from the ground up: LLM and video generation pipelines, async job orchestration and a credit billing engine.

I like the hard parts of backend work: **concurrency, performance, security and reliability**.

### ⚡ Highlights
- 🚀 Raised payment throughput **6x** by simplifying how core transaction services communicate
- 🔐 Cut authorization latency by **~95%** (150 ms → 5–10 ms) across 10+ services with a shared Redis cache
- 💳 Built a billing engine with idempotent transactions, row-level locking, an audit ledger and Razorpay payments
- 🤖 Orchestrated LLMs (Claude, Gemini, GPT) and 6+ image and video models in production
- 🛡️ Led security hardening across 6+ banking services: encryption, MFA, RBAC and token revocation
- 🌱 Open source: [contributed a fix to **Celery**](https://github.com/celery/celery/pull/10896) to keep Celery Beat running when a schedule entry fails
